# Flotilla suggestions library: published

What Flotilla downloads: `library.json`, `library.json.sig` (its Ed25519 signature) and `icons/`,
the suggestions' logos, each covered by the SHA-256 that `library.json` lists. Only the owner
publishes here, signed on his Mac. The entries, tools and checks live on
[`main`](https://github.com/melonfleet/flotilla-library/tree/main).
